# ADrop Android Client

Official offline Android client for **ADrop** — High-speed offline local file transfer between PC & Mobile.

## Features
- **Native Fullscreen UI**: Pure standalone experience without browser URL bars or limitations.
- **Built-in Camera QR Scanner**: Connect to your PC in 1 second by scanning the dashboard QR code.
- **Background WakeLock**: Transfers never get interrupted or throttled when the phone screen turns off.
- **Native File Chooser**: Upload photos, videos, and multi-GB documents from phone to PC.
- **System Download Manager**: Saves downloaded files directly to the phone's public `Download/` folder.

## Automated Cloud Build
Powered by GitHub Actions. Every push to `main` automatically compiles, signs, and generates the latest release APK artifact.
